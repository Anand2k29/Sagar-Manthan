## 🔴 The Problem

India possesses the **7th largest Exclusive Economic Zone (EEZ)** in the world — 2.37 million km² of ocean territory — yet its marine data infrastructure suffers from critical fragmentation:

| Challenge | Impact |
|-----------|--------|
| **Siloed Data Systems** | INCOIS, CMLRE, Fishery Survey of India (FSI), NIOT, and state fisheries departments maintain independent databases |
| **No Unified Analytics** | No single platform integrates oceanographic data (currents, SST, salinity), fisheries data, and eDNA molecular biodiversity |
| **Manual Taxonomy** | Species identification relies heavily on manual taxonomy; stock assessment data processing takes months |
| **Energy-Biodiversity Conflict** | India targets 30 GW offshore renewable energy by 2030, but lacks tools to balance energy yield against environmental impact |
| **Data Privacy Barriers** | Research institutes resist sharing raw biodiversity data due to sovereignty concerns, preventing unified model training |

**Bottom line:** India is sitting on an ocean of data but drowning in fragmentation.

## 🏆 Key Features & Platform Architecture

### 1. 🏛️ Official Government Executive Command Console
- Built directly into the Hero landing section for high-level decision support.
- **Target EEZ Sector Selector**: Direct sector targeting (*Zone-7 Kerala Coast, Zone-3 Gulf of Kutch, Site-9 Kanyakumari, Andaman & Nicobar, Lakshadweep Atolls*).
- **Operational Module Selector**: Direct entry into GIS Map, 3D Spatial Sonar, Otolith AI, eDNA Digital Twin, or Gemini AI Bot.
- **Quick Directives**: 1-click execution chips (`🗺️ 12-Layer Map`, `🔊 3D Sonar HUD`, `⚡ 42 GW Wave Siting`, `🔬 Otolith AI`).

### 2. 🎛️ Ministerial Decision & Intelligence Radar (5-5 Grid Layout)
- Visual 10-icon circular deck arranged in a balanced **2-row 5-5 grid**:
  - 🌐 **GIS MAP**: 12-Layer EEZ Geospatial Contours
  - 🌡️ **SEA TEMP**: SST Satellite Thermal Monitoring
  - 💨 **CURRENTS**: WICC Vector Streamlines
  - 🐟 **FISH ROUTES**: Sardine Migration Corridors
  - 🔬 **OTOLITH SCAN**: Vision v3.2 Species Taxonomy AI
  - 🧬 **eDNA RADAR**: GenBank Molecular Barcode Alignment
  - ⚡ **WAVE ENERGY**: Hydrodynamic Digital Twin Simulator
  - 🔊 **3D SONAR**: 200 NM Hydroacoustic Radar HUD
  - 🛡️ **EXCLUSION**: Schedule I Marine Wildlife Shield
  - 💬 **AI ASSISTANT**: Gemini 1.5 Pro Decision Advisor

### 3. 🌐 New Tab Deep-Linking System
- Clicking **any feature button, service icon, directive chip, or ecosystem card** on the landing page opens the targeted module in a **new browser tab** (`?tab=map`, `?tab=otolith`, `?tab=spatial-sonar`, etc.).
- The original tab stays open on the **Landing Page as it is**.
- Deep-linked URLs initialize state directly into the target feature module without re-rendering the landing page.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18+
- [npm](https://www.npmjs.com/) v9+

### Installation & Execution

1. **Clone Repository**
   ```bash
   git clone https://github.com/Anand2k29/Sagar-Manthan.git
   cd Sagar-Manthan
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   Create a `.env.local` file in the root directory:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Launch Development Server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

5. **Build for Production**
   ```bash
   npm run build
   ```
